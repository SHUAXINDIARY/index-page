# UI 可访问性静态审查

日期：2026-11-18。范围为 src 下全部 UI 组件、桌面和移动布局、全屏模式、主题面板及 HTML 入口。

本次保留默认视觉、尺寸、配色、鼠标操作、导航目标和业务流程。仅补充语义、读屏信息、键盘等价操作、焦点管理和系统高对比度适配。

## 已处理

| 范围 | 发现与调整 |
| --- | --- |
| 页面结构 | 增加 main 和隐藏的一级标题；校正卡片在可访问性树中的标题层级，保留原标签对应的样式。 |
| 个人菜单 | 点击 div 改为原生按钮并重置原生外观；保留原点击回调，补充头像说明、弹窗类型和 iframe 名称。 |
| 文章 | 用覆盖原卡片点击区域的原生链接提供键盘入口，保持原目标和新窗口行为。 |
| 社交链接 | 为图标链接补上站点名称，装饰图标不再单独播报。 |
| 音乐 | 播放、暂停、加载和下一首具有名称和状态；进度条提供数值，未播放时不将展示占位当作真实进度。 |
| 自定义弹层 | iframe、开源项目、全屏轮播、全屏地图及移动主题面板补充名称、焦点进入、Tab 边界、背景 inert 和焦点恢复；沿用原 Portal、动画、ESC 和关闭回调。 |
| 主题设置 | 补充展开、选中、控件关联和 Escape；颜色输入与背景图复选框有显式标签关联。 |
| 轮播 | 隐藏项退出可访问性树与 Tab 顺序；提供键盘全屏及方向键切换，键盘焦点位于轮播内时暂停自动切换，减少动态偏好下关闭自动切换。 |
| 地图 | 图例改为保留原样式的原生切换按钮；补充缩放、复位、平移键盘操作，修复焦点进入照片链接时提示被卸载的问题。 |
| 日历和时钟 | 日期说明具有有效角色，标记今天；时钟整体提供时间文本，避免动画数字重复读取，不每秒主动播报。 |
| 画布 | 视图支持键盘平移、缩放和复位；标签与表单控件显式关联，滑块提供单位；控件分组使用有效角色。三维预览允许传入替代说明。 |
| 键盘焦点 | 为已有 outline: none 的控件补充 focus-visible；仅键盘焦点可见，不改变鼠标外观。 |
| 高对比度 | 系统强制颜色模式提供边界与选中态；颜色样本保留本色，不改变默认主题。 |

## 当前约束下仍需确认

- 默认次要文字、半透明卡片、自定义主题和背景图片组合的实际对比度，需要在真实渲染后逐一测量。若不足 4.5:1（普通文字）或 3:1（大型文字、非文字控件），修复需要调整视觉颜色，与本次不改变 UI 的约束冲突，因此未直接改色。
- 自动轮播尚无独立、可持续暂停的可见控件；本次补充焦点暂停和减少动态偏好支持，未增加按钮或改变已有鼠标自动轮播流程。完整满足自动更新内容的暂停要求仍需产品交互调整。
- 图片的具体内容说明、音乐的文本替代由实际内容决定，不能从文件名或音频标题推断。现有图片说明和音乐配置需内容所有者确认。
- WebGL 中新增图形、三维物体操作和第三方 Shadow DOM 的完整读屏结构，以及放大文本后的裁切、触控目标和焦点遮挡，不能仅通过静态代码证明。跨域 iframe 的内部可访问性由目标站点负责。
- 自定义弹层为保留现有动画与布局而未改为 native dialog。焦点隔离使用 inert，需在项目支持的浏览器及嵌入 iframe 场景下验证。
